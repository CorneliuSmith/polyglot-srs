# Common learner errors — Swahili (sw)

_Extracted from source documents; review before folding into ERRORS.md._

## Asking about time, manner and kind: lini, vipi, gani, mbona
- Moving the interrogative to the front as English does: lini utaondoka rather than utaondoka lini.
- Giving gani a class concord, when it never takes one.
- Using mbona for a neutral 'why', where kwa nini is the unmarked choice.

## Asking for and giving directions
- Using iko for every noun, when the copula must carry the noun's own class prefix.
- Saying kulia for 'to eat with' or 'to cry' without noticing the identical infinitive.
- Omitting upande wa before kulia or kushoto in careful speech.

## Numbers 11 to 100, and talking about prices
- Giving a concord to sita, saba, tisa or the tens, which never take one.
- Omitting na between the ten and the unit: kumi saba instead of kumi na saba.
- Putting the number before the currency noun rather than after it.

## Negative infinitives with -to-: kutojua, kutokuwa
- Using -si- in an infinitive: kusijua instead of kutojua.
- Using -to- in a command, where the negative subjunctive -si- is required.
- Dropping the second ku- from monosyllabic stems: kutowa instead of kutokuwa.

## The -enye construction: possessing a quality
- Leaving -enye without a concord, or giving it the wrong class.
- Following -enye with a verb rather than a noun.
- Using na alone where -enye is needed to modify a noun.

## Greetings with habari and the possessive concord
- Using yako for a group, where yenu is required.
- Putting a possessive before a noun instead of the associative ya: habari yako asubuhi rather than habari ya asubuhi.
- Answering a greeting with a bare mzuri where the noun class calls for nzuri.

## Introducing yourself: naitwa and jina langu
- Using the class 9 possessive with jina: jina yangu instead of jina langu.
- Adding a subject pronoun where the prefix already carries it: mimi naitwa is emphatic, not neutral.
- Confusing -itwa (be called) with -ita (call somebody).

## Telling the time: the Swahili saa system
- Reading saa moja as one o'clock rather than seven.
- Omitting the period word, which leaves the hour ambiguous between day and night.
- Using a concord on ngapi that does not match saa, which is class 9.

## Politeness formulas: asante, tafadhali, samahani, pole, karibu
- Saying pole to apologise for your own action, where samahani is required.
- Forgetting the -ni plural suffix when addressing a group: asante and karibu become asanteni and karibuni.
- Treating karibu only as a welcome, when it is also the standard reply to thanks.

## Talking about illness: ninaumwa na and inaniuma
- Translating 'I have a headache' with kuwa na: nina kichwa means 'I have a head'.
- Giving the active verb a subject prefix that agrees with the person rather than the body part.
- Omitting na after ninaumwa, which leaves the body part unattached.

## Ordinal numbers: wa kwanza, ya pili, cha tatu
- Using moja for 'first' instead of kwanza.
- Using mbili for 'second' instead of pili.
- Giving the linker the wrong class concord: siku wa pili instead of siku ya pili.

## Impersonal verbs: inabidi, inafaa, inawezekana
- Making the person the subject: ninabidi instead of inanibidi.
- Following the impersonal verb with an infinitive where a subjunctive is required.
- Adding an object infix to lazima, which is a noun and takes none.

## Dates, months and birthdays
- Giving the date number a class concord, which it does not take after tarehe.
- Putting the month before the number, reversing the Swahili order.
- Translating 'birthday' word for word instead of using siku ya kuzaliwa.

## States expressed with nina: njaa, kiu, wasiwasi, huzuni
- Using ni for a state: mimi ni njaa instead of nina njaa.
- Confusing nina baridi (I feel cold) with kuna baridi (the weather is cold).
- Forgetting that the negative uses si-, not ha-, in the first person singular.
